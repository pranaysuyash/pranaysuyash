## How I work

- Start with real artefacts: files, screens, data, calls, support cases, constraints, and failure modes.
- Move between the commercial goal, operating workflow, interface, architecture, and code when the decision requires it.
- Separate what is known, inferred, and still risky.
- Prefer working software, explicit decisions, and inspectable evidence over confidence theatre.
- Treat error states, packaging, documentation, release gates, and handoff as part of the product.
